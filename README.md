# Zayaana Mohammed — Portfolio Site

A personal portfolio / resume website built with plain HTML, CSS and JavaScript.

## Features

- **Hero** — animated typed-role subtitle, skill badges and call-to-action buttons
- **About** — background, diploma and quick-stat cards
- **Skills** — animated progress bars for all 7 specialisations (UI/UX, Data Analytics, Web Dev, Full Stack, Cloud, Public Speaking, Technical Writing)
- **Projects** — card grid showcasing 6 featured projects
- **Experience** — vertical timeline of education and work
- **Contact** — mailto / social links + message form

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | Semantic HTML5 |
| Styling | Custom CSS (variables, grid, flexbox, animations) |
| Scripting | Vanilla JavaScript (IntersectionObserver, typed effect) |

## Getting Started

Just open `index.html` in a browser — no build step required.

```bash
open index.html
```

Or serve it locally:

```bash
npx serve .
```
